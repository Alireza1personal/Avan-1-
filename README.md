# divar-bot-region1

ربات دیوار (مشهد، **منطقه ۱**) → تلگرام + صف بررسی پنل مادر (Neway)

خواهرخواندهٔ ریپوی منطقه ۹/۱۱. همان کد؛ فقط محله‌ها و منطقه فرق دارد.
سیکرِت‌ها را جدا بگذارید (گروه/تاپیک تلگرام و در صورت نیاز توکن ربات پنلِ همین منطقه).

## محله‌ها

آبکوه، آپارتمان های مرتفع، احمدآباد، ارشاد، بهاران، بهشت، جانباز، راهنمایی، زمانه، سجاد شهر، سعدآباد، **سناباد**، فرامرز عباسی، فردوسی، فلسطین، کلاهدوز، کوه سنگی، گوهرشاد، ملک آباد، نوفل لوشاتو.

`سناباد` در لیست اول جا افتاده بود و این‌جا اضافه شده. باید در درخت محله‌های اپ مادر، زیر مشهد › منطقه ۱، هم ساخته شود وگرنه فیلتر مشاورها آن را نمی‌بیند.

نام پنل عین برچسب دیوار است. به‌خصوص:
- دیوار «سجاد» جدا ندارد؛ برچسبش **سجاد شهر** است (`sajjad-shahr`).
- برچسب دیوار **کوه سنگی** است (با فاصله)، نه «کوهسنگی». املای چسبیده فقط alias است.

## Secrets (GitHub → Settings → Secrets and variables → Actions)

| Secret | توضیح |
|--------|--------|
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام |
| `CHAT_ID` | آیدی گروه (مثلاً `-100...`) |
| `TOPIC_SELL` | آیدی عددی تاپیک فروش |
| `TOPIC_RENT` | آیدی عددی تاپیک اجاره |
| `NEWAY_API_URL` | پایه API بدون `/` آخر (مثلاً `https://api.example.com`) |
| `NEWAY_BOT_TOKEN` | توکن `nwb_...` از پنل (super_admin → ربات‌ها) |

## اجرا

Actions → Divar Scraper → Run workflow

لاگ موفق:
```
پنل مادر: فعال → https://...
✅ پنل مادر ← ثبت شد
✅ تلگرام → تاپیک ...
```

## API پنل

`POST {NEWAY_API_URL}/admin/mother-properties`  
Header: `X-Bot-Token: nwb_...`
